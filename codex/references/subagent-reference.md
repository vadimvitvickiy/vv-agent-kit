# Subagents in Codex

Use the collaboration tools and contracts available in the current session. Role
skills `$vvkit-architecture-surveyor`, `$vvkit-commit-reviewer`, and
`$vvkit-test-runner` provide instructions to pass to a generic agent or apply inline.
They are not agent configuration files. The Swift reviewer skill exists only in the
project where the Swift pack was installed.

Supply objective, known paths, ruled-out approaches, and an output contract with
evidence. Use read-only tasks for review and surveying, except for a requested report.
Keep one writer in a shared working tree. Follow current delegation authorization,
model and history-fork rules. Do not assume nested agents are forbidden or available:
check the actual tool contract. Do not copy Claude tools, model, memory or isolation
frontmatter into Codex configuration. Where configured roles are needed, consult
https://learn.chatgpt.com/docs/agent-configuration/subagents first.
