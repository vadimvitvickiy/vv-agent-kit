# Reconcile project instructions

Read the actual instruction file and inventory installed user and project skills.
For each rule, identify exact coverage in an installed SKILL.md before replacing
it with a reference. Preserve project facts, response preferences and enforcement
requirements. Keep rules with no equivalent. A topic match is not proof of coverage.

Show the mapping when it helps review. Apply authorized edits, account for every
original rule, and report which formerly unconditional rules now depend on skill
selection. Do not rewrite a AGENTS.md into AGENTS.md through global search/replace;
preserve existing files and their separate consumers.
