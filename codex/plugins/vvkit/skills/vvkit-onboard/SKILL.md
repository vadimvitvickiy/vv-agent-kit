# Onboard a repository

Inspect existing AGENTS.md, AGENTS.md, project configuration, build manifests, tests,
CI, recent commits and generated files. Preserve existing guidance. Verify every
asserted convention against code or runnable commands before recording it.

Create or merge concise AGENTS.md guidance with commands, invisible constraints and
references to installed skills. Put reusable project skills in .agents/skills.
Honor the user's requested scope; do not install companion plugins, add hooks or
replace instruction files merely because the source Claude kit did so. For build
script generation use $vvkit-scripts. Keep architecture facts that cannot be derived
from code in project documentation, and generated maps separate.
